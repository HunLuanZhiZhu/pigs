# Archived prompts

This directory contains superseded prompt templates kept only for historical comparison and experiment provenance.

They are not part of the current runtime prompt set and must not be referenced by new `include_str!` calls. Current runtime templates live one directory above.

Archived groups include the former model-specific Pre templates (`pre_deepseek_*`, `pre_muse_*`, `pre_generic_*`), the former standalone full-path Pre templates (`pre_full_*`), the former monolithic adaptive Pre templates (`test_pre_user_*`), and superseded Pre/Exec/Post templates (`pre_user_*`, `exec_user_*`, `executor_user_*`, `post_user_*`).
